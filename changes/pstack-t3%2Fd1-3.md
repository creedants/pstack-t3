- `scripts/run_tests.py` records original protected roots in `PSTACK_TEST_PROTECTED_ROOTS` before rewriting child environments. `install()` and `worker_env` pass recorded roots on, including through nested runners. Removing or rewriting that variable, clearing the environment, or passing an empty environment to `worker_env` can drop original external XDG protection. Colon-containing paths cannot round-trip through its colon-separated format
- `mark()` and `worker_env()` in a guarded process accept only a directory inside its run root or one it allocated with `allocate`. Adoption still trusts caller-written metadata. A deliberately forged marker with this user's UID, a live PID, a chosen token, and the directory's device and inode can let a child adopt an existing directory and delete its contents
- A marker records the directory's device and inode. Adoption compares those fields with the directory, so copying a marker unchanged to another directory is refused
