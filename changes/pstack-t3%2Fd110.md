- `brigade.py ticket add --from-report reports/D2.md` files one waiting ticket for each follow-up in a worker's item report, with source `report` and a ref such as `perf/reports/D2.md#3`. It reads list items and, in a section with no list, paragraphs. It skips a follow-up whose text a ticket in any state already holds, so a second run on the same report adds nothing. `--dry-run` prints what a run would add and writes nothing. Each worker brief now asks for a `## Follow-ups` section with one top-level list item per follow-up, and the brigade skill tells the coordinator to run the command after a passing review.
