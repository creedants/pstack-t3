- `brigade.py ticket add --from-report reports/D2.md` files one waiting ticket for each follow-up in a worker's item report, with source `report` and a ref such as `perf/reports/D2.md#3`. It reads list items and paragraphs. It prints, and does not file, a paragraph that introduces a list, a paragraph after a section's last list item, and an item that only says no work is needed, such as `None.` or `No README edit is needed.` It skips a follow-up whose text a ticket in any state already holds, so a second run on the same report adds nothing. It refuses a report that is a symbolic link or that resolves outside the store's `reports/`. `--dry-run` prints what a run would add, takes no lock, and creates or changes no file. Each worker brief now asks for a `## Follow-ups` section with one top-level list item per follow-up, and the brigade skill tells the coordinator to run the command after a passing review.
