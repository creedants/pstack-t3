- `install` and `uninstall` now exit 3 when the run printed a line that begins `skipped`. The run still does its other steps and prints its summary line before it exits. A dry run never exits 3. Lines that begin `kept` or `left`, and `nothing to link` lines, do not change the exit status. Exit 1 for a run that stops before its summary and exit 2 for a usage error are unchanged.
- When uninstall restores a backup, or removes this checkout's link from a backup that another checkout's `--replace` made, it now removes that backup's `backups/<stamp>/<harness>` directory if it is empty, then the `<stamp>` directory if that is empty. A run that finishes an interrupted restore does the same. Nothing else is removed. `backups/` stays, a directory that holds anything stays, a directory that another run left empty stays, and a backup recorded outside `backups/<stamp>/<harness>/` or reached through a symlink leaves its directories in place.
- `doctor` now reads the install records. Under each selected harness it prints this checkout's recorded links that prove neither at their path nor in a recorded backup, backup records with nothing at their backup path, and owner files of other checkouts whose checkout directory is missing. Each line names a command to run, or the entry or file to delete. `doctor` takes no lock and writes nothing, and these lines do not change its exit status. When a record file cannot be read, `doctor` names it in one line and still runs the checks that do not need it.
