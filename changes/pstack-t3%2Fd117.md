- roles: one definition of a model's family decides every diversity check. A provider path or a Bedrock prefix no longer makes a second family, so the default `verifiers` panel seats one of `opencode/muse-lite-2-free` and a bare `muse-lite-2`, and a built-in seat with no exact `grok-4.7` picks `x-ai/grok-4.8` as a `missing model`.
- roles: `show` and `validate` apply `backup`'s rules to a configured `review backups` role. With a catalog, `show` prints the seats `backup` keeps when no provider is out and no author is named, and a note with the reason for each dropped seat. Without a catalog it prints `catalog-required`. `validate` prints each dropped seat as a problem and exits 1, so `write` refuses it without `--force`.
- roles: the `has no seat` error names only the excluded kinds among the models it lists. For `show --launches-seats` it names the runnable providers of the launch pool, or says that none of the pool's providers can run child tasks.
