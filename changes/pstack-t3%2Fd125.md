- `brigade`: a new script, `activity.py`, prints one HTML page of a coordinator's agent and sub-agent activity for a window of hours, 3 by default. It opens the coordinator's store and T3 Code's state database read-only, and it exits with status 3 and one line when that database is missing, unreadable, or a shape it does not read. `--text` prints plain lines instead. The skill's new Agent activity section tells the coordinator to show the page when the user asks for it, and the runtime's Visual reports section allows that page at `digest`. Its reference is `docs/cli/activity.md`.
