- `scripts/install.py` and `roles.py` now treat an `XDG_CONFIG_HOME` that is not empty and not an absolute path as unset.
- A run of either tool that reads such a value prints one line on stderr, `XDG_CONFIG_HOME='<value>' is not an absolute path, so it is ignored and the config home is '<path>'`.
- Set `XDG_CONFIG_HOME` to the full path of a config home an earlier run used under a relative value to make the tools read that directory again.
- `uninstall` now prints `kept backup row <backup>: a relative path with nothing at it from this working directory (recorded as the backup of <original>); uninstall reads a relative path from the directory it runs in` for a backup row whose `backup` is a relative path with nothing at it from the working directory, when no `.pstack-t3-*` directory beside that path holds an entry under its name and every harness of the row is selected.
- `doctor` now prints `backup row <backup>: a relative path with nothing at it from this working directory (recorded as the backup of <original>); uninstall reads a relative path from the directory it runs in; to drop the row, delete it from "backups" in <manifest>` for a backup row whose `backup` is a relative path with nothing at it from the working directory, when no `.pstack-t3-*` directory beside that path holds an entry under its name.
- `roles.py write` now writes `roles.json` and `catalog.json` under an `XDG_CONFIG_HOME` whose `..` follows a symlink when `pstack-t3` under the `os.path.abspath` spelling of that value does not exist, where it ended in a traceback.
- `roles.py write` no longer leaves its temporary file behind when writing or renaming it fails.
- The `roles.py` refusal to inherit a parent model pstack excludes now ends `<provider> is not runnable (<constraints>)` when the catalog lists the provider and its `canRunChildTask` is not true, with `cannot run child tasks` in the parentheses when the provider lists no constraint.
- `install`, `uninstall`, and `doctor` now exit 1 with the one line `<NAME>='<value>' is not an absolute path, and the system could not name this run's working directory (<reason>); change to another directory and rerun` on stderr when `os.getcwd()` fails and either `HOME` is set and not absolute or `CLAUDE_CONFIG_DIR` is not empty and not absolute. A run of `install` or `doctor` that stops on its `skills` line, and a run that stops on its line for a relative `--project`, prints that line and not this one.
- `install` and `doctor` now print `skills is not a directory; move it away, then run python3 scripts/build.py` when something that is not a directory is at `skills`, where they printed `skills/ is missing; run python3 scripts/build.py first`.
- `uninstall` no longer ends in a traceback when a backup row whose `backup` holds a NUL byte names an `original` this checkout links.
- `scripts/install.py` now prints text that stdout's error handler refuses as a backslash escape, where the run ended in a traceback.
