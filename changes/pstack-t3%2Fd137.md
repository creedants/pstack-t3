- `scripts/install.py` and `roles.py` now treat an `XDG_CONFIG_HOME` that is not an absolute path as unset.
- A run of either tool that reads such a value prints one line on stderr, `XDG_CONFIG_HOME=<value> is not an absolute path, so it is ignored and the config home is <path>`.
- Set `XDG_CONFIG_HOME` to the full path of a config home an earlier run used under a relative value to make the tools read that directory again.
- `uninstall` now prints `kept backup row <backup>: a relative path with nothing at it from this working directory (recorded as the backup of <original>); rerun uninstall from the directory where that path names the backup` for a backup row whose `backup` is a relative path with nothing at it, when every harness of the row is selected.
- `doctor` now prints `backup row <backup>: a relative path with nothing at it from this working directory (recorded as the backup of <original>); uninstall reads that path from the directory it runs in, so run it from the directory where the path names the backup; to drop the row instead, delete it from "backups" in <manifest>` for such a row with no entry held aside for it, where it advised deleting the row.
- `roles.py write` now writes `roles.json` and `catalog.json` under an `XDG_CONFIG_HOME` whose `..` follows a symlink when the directory its `os.path.abspath` spelling names does not exist, where it ended in a traceback.
- `roles.py write` no longer leaves its temporary file behind when writing or renaming it fails.
- The `roles.py` refusal to inherit a parent model pstack excludes now ends `<provider> is not runnable (<constraints>)` when the catalog says the provider cannot run child tasks, with `cannot run child tasks` in the parentheses when the provider lists no constraint.
- `install`, `uninstall`, and `doctor` now exit 1 with the one line `<NAME>=<value> is not an absolute path, and the system could not name this run's working directory (<reason>); change to another directory and rerun` when `os.getcwd()` fails and either `HOME` is set and not absolute or `CLAUDE_CONFIG_DIR` is not empty and not absolute.
- `install` and `doctor` now print `skills is not a directory; move it away, then run python3 scripts/build.py` when something that is not a directory is at `skills`, where they printed `skills/ is missing; run python3 scripts/build.py first`.
- `uninstall` no longer ends in a traceback when a backup row whose `backup` holds a NUL byte names an `original` this checkout links.
- `scripts/install.py` now prints text that stdout's error handler refuses as a backslash escape, where the run ended in a traceback.
