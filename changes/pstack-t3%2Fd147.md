- `land.py land` reads the author of each commit between an entry's base and its reviewed commit. It does that after a replay that passes the conflict and fingerprint checks, and before it opens a pull request for an entry awaiting merge that has none. When an author name or email differs from `git config user.name` and `git config user.email` read in the repository, it bounces the entry with `bounced E<n> (<holder>): commit <sha12> has author <name> <<email>>, not the configured <name> <<email>>; recommit it as the configured author`. The check does not run when either value is unset, and an entry whose change is already in trunk is not checked. A commit with another author passes when the entry's body has a line that reads `Based on #<n> by @<login>`, with or without a final period, and the commit has a `Co-authored-by` trailer equal to its own author as `<name> <<email>>`. `<n>` is digits, and `<login>` is letters, digits, and hyphens. The body is the text of the file given to `submit --body-file`. When that text is empty or no file was given, it is the message body of the reviewed commit. Every `land.py` command except `slot` stops when the common `config` file sets `core.worktree` to a value where git does not find the repository. It prints `land: <config path> sets core.worktree to <value>, where git does not find this repository; remove it with git config --file <config path> --unset-all core.worktree`, exits 1, and leaves the file unchanged.
