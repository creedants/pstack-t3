- `brigade`: the filter of `activity.py` now also removes four kinds of text. The whole request name of a delegated task, when that name is letters and digits joined by single hyphens and stands as a whole such run with no slash that starts the word before it. An absolute path of two or more segments whose first segment starts with a hyphen or a plus sign, or that starts with two slashes. A path the run read of fewer than 4 characters, as a whole word. An email address with a quoted local part of at most 62 characters, or with a bracketed host of four numbers. The script exits with status 3 for a sub-agent row that makes a thread its own parent or ancestor even when another row gives that thread a different parent. Work items whose shortened id, summary, state, and link print alike are each listed or counted in both forms.
