- `brigade.py brief` refuses a brief with no contract. `--contract <text>` or the `contract` key of the `--fields` file gives it, and the text `none` is a contract like any other. The brief renders it under `CONTRACT:` between `ACCEPTANCE:` and `VERIFY:`, and the new `contract <item>` command prints the one the item's last brief stored. `close` prints a warning for each item that is in review or passed and whose `reports/<item>.md` is a regular file in the store's `reports/` with no Claims check line.
- `brigade.py pass record` takes the verdict `pass-with-edits` with `--edits <review report>`, and refuses a report whose `## Edits` section holds no edit or an edit that does not parse. The row moves the item to sent-back unless `--member` or `--late` is given, and it counts toward neither the round budget nor the move to full mode after two send-backs. The new `edits verify <item> --from <sha> --to <sha>` command applies that round's edits to a scratch copy of the reviewed commit, runs the build command there unless it is `none`, and compares the copy with the head at every path either commit holds where the two commits differ or the edits or the build changed the copy. When every path agrees it runs the check command there unless it is `none`, and a run with no failure adds one row to the new `edits.tsv` table unless an equal row exists. `set --build-command` and `--check-command` record the two commands, and `edits verify` refuses to run until both are set. `pass record --verdict pass` without `--member` is refused while the item's last row that is not a `--member` row is `pass-with-edits`, unless `edits.tsv` holds a row for that round and this head or `--report` names a review report other than that round's.
