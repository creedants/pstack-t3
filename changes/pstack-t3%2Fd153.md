- `land.py land` now remembers the git identity it runs as and pauses the queue when that identity changes. The identity is `git config user.name` and `git config user.email` read in the repository, with no character removed. A `land` run on a queue that is not paused reads it before it fetches trunk or settles an entry. With no identity remembered, it remembers the pair when both values are non-empty, and it runs. It remembers nothing while either value is unset or empty. That holds for the first run of this version on a queue that already landed entries, which compares against nothing. With an identity remembered, it pauses unless the name and the email both equal the remembered ones, character for character. Surrounding spaces and letter case count as differences. The pause prints `queue paused: the configured git identity is now <name> <<email>> and the queue last ran as <name> <<email>>; check git config --show-origin user.email in <repo>, then run land.py resume`. When either value is unset or empty after one was remembered, it prints `queue paused: the configured git identity is now unset (user.name and user.email do not both have a non-empty value) and the queue last ran as <name> <<email>>; check git config --show-origin user.email in <repo>, then run land.py resume`. That run prints no other line. It opens no pull request, pushes nothing, and changes no entry or lease. It stores the pause and logs it. A later `land` prints the stored line and does not read the identity again. `land.py status` with no argument shows the same reason after ` Paused: `. `land.py resume` forgets the remembered identity only when the pause it clears is this one. The next `land` then remembers the pair configured at that time, or nothing when either value is unset or empty. A `resume` that clears another pause, or runs with no pause set, keeps the remembered identity. In `<name>`, `<email>`, and `<repo>`, a backslash or a character that ends a line for Python's `str.splitlines` is printed as its Python escape. The help for `resume` now reads `clear a pause after you did what its reason says`.
