- `tests/test_brigade.py` removes every variable whose name starts with `GIT_` from `os.environ` when the module starts, and sets `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` to the null device. It restores `os.environ` when the module ends. The git commands the tests run, directly or through a script, receive no `GIT_*` variable from the caller and read no global or system git configuration. The module passes under a `HOME` whose `.gitconfig` holds an identity.
