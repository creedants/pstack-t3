- The landing skill now covers three `land.py` outputs. A bounce that reads `commit <sha12> has author <name> <<email>>, not the configured <name> <<email>>; recommit it as the configured author` says to recommit as the configured author, or to give another author a `Co-authored-by` trailer and a `Based on #<n> by @<login>` line in the body, which is the text of the file given to `submit --body-file` or the reviewed commit's message body when that text is empty or no file is given, and the list of what bounces a rebuild names it. A stop that reads `land: <config path> sets core.worktree to <value>, where git does not find this repository; remove it with git --work-tree=. config --file <config path> --unset-all core.worktree` says to run the printed command and then the command again. A pause that starts `the configured git identity is now` says it is the user's call, to report it, and to run `resume` only after the config is restored or the user confirms the new identity.
