- `scripts/catalog.py` resolves the file of each bullet in the built poteto-mode Playbooks list. The file is the backticked `playbooks/<name>.md` that ends the bullet, with or without a `File: ` lead-in. A bullet that does not end with one resolves to `playbooks/<title in kebab case>.md`, where kebab case lowercases the title, drops every character other than `a` to `z`, `0` to `9`, the space, and the hyphen, and then turns each space into a hyphen. `python3 scripts/build.py` fails with `poteto-mode/SKILL.md: playbook "<title>" resolves to <file>, which does not exist` when that file is missing from the built tree. `python3 scripts/check.py` run alone does not make this check. The poteto-mode Playbooks list no longer carries a file on 20 bullets and carries upstream's `File: ` lead-in on three. `docs/skills.md` lists `ketchup` under Understand and has no Other section. The built `ketchup` skill has no runtime pointer paragraph.
