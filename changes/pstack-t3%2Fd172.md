- `roles.py write` refuses a seat on a metered OpenCode model unless that same file's `opencodeAllow` list names the full model id, and it writes nothing unless `--force` is passed. A model is free only when its catalog object has `cost`, `pricing`, or `tier` and every one of those present values is `0` or `free`. Otherwise the model is metered, including when those keys are absent. `show`, `backup`, and `validate` note that seat and do not refuse or rewrite the file. The user file's list and the project file's list stay separate.
