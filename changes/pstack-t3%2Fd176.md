- `scripts/sync_upstream.py` rewrites only the README upstream badge url and alt version spans when it writes `upstream.json` and preserves every other byte and line ending. It exits 1 before that write when the badge line is missing or not that one line. It exits 1 before that write when the new version is not a dotted number and names that version as not carriable by the badge. `scripts/check.py` names `README.md` and both versions when the badge url or alt differs from the `upstream.json` version. It names `README.md` and that version when the badge is absent. That check runs at the default CLI and in the build and not in `check_tree`. The build fails on that finding.
