- `threads.tsv` holds one row per thread an item used, with the time the row was written, the item, the attempt, the role, the thread id, the seat, the start, and the end. `open` writes its header, and a store with no such file gains it on the first write that adds or closes a row. The roles are worker, fix worker, reviewer, panel member, code delegate, claims check, and architect runner, and a role that is not one of them is refused by name. Each of the seven has one writer. `dish <item> --thread <id>` writes the worker rows, and the attempt and the worker role come from the worker rows the item already holds, so attempt 1 is role worker and every later attempt is role fix worker. `pass record --reviewer-thread <id>` writes the reviewer row and takes its seat from `--verifier`. `thread <dish> --role "panel member" --thread <id> --seat <provider/model>` writes the panel member row. A `## Threads` section of `reports/<item>.md` writes the code delegate, claims check, and architect runner rows, and a report that lists no child adds no row and is not an error. A line the parser cannot read is refused by its line number and adds no row, and every refusal happens before the `pass.tsv` append. `--member` takes no `--reviewer-thread`. Every write is idempotent for the same item, attempt, role, and thread, and `drop`, `dish --reported`, and a state change close the item's open worker rows.
