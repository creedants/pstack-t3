- `threads.tsv` holds one row per thread an item used, with the time the row was written, the item, the attempt, the role, the thread id, the seat, the start, and the end. `open` writes its header, and a store with no such file gains it on the first write. The roles are worker, fix worker, reviewer, panel member, code delegate, claims check, and architect runner, and a role that is not one of them is refused by name. `dish <item> --thread <id>` writes the row for the current attempt, and the attempt and the worker role come from the worker rows the item already holds, so attempt 1 is role worker and every later attempt is role fix worker. `pass record` writes a reviewer row when it is given `--reviewer-thread`, taking the seat from `--verifier`, and it files one row per child a `## Threads` section of `reports/<item>.md` lists. A report with no such section adds no row and is not an error, a line the parser cannot read is refused by its line number and adds no row, and every refusal happens before the `pass.tsv` append. `thread <dish> --role <panel member|architect runner> --thread <id> --seat <provider/model>` writes one row for a role no other command writes, and `--member` takes no `--reviewer-thread`. Every write is idempotent for the same item, attempt, role, and thread, and `drop`, `dish --reported`, and a state change close the item's open worker rows.
