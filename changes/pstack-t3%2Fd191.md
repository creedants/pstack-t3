- A command waiting 15 seconds for a governor slot prints one stderr line naming each holder it waits behind by kind, repository, hold duration, and short command, or as unknown when no record proves the holder, then one more line every 60 seconds.
- `land.py slot` samples the slots a waiter reports on while it still holds the turn mutex, so a reporting probe holds no slot lock where another caller's eligibility check can see it. A record names its writer only while that writer holds an exclusive lock on the record's own file, held from the moment the slot is taken until after the slot handles close. A record whose writer is gone therefore reads as unknown, and so does a slot that an older `land.py` copy took without writing a record.
