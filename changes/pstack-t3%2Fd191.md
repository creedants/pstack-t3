- A command waiting 15 seconds for a governor slot prints one stderr line naming the distinct holders of the busy slots of the kind it is trying to take, by kind, repository, hold duration, and short command, with unknown when no lock conflict proves a writer, when the record is missing, empty, or malformed, and for each field a proven record does not carry, then one more line every 60 seconds. A worker waiter describes busy worker slots. A landing waiter describes the landing slot when it is busy. An exclusive waiter names the distinct holders of every busy slot.
- The reporting probe in `land.py slot` covers only the slots of the kind its waiter is trying to take, and it runs while that waiter holds the turn mutex. A worker waiter probes the worker slots. A landing waiter probes the landing slot. An exclusive waiter probes every slot. Callers that consult the turn file cannot observe a reporting probe's temporary slot lock. Within that kind, the probe can still lock a free slot for the time between the two adjacent system calls. An older copy that does not consult the turn file can observe that lock. The record lock starts in `_dump_holder`, after the slot is taken, on the temporary inode before its atomic rename. Normal context exit calls `_clear`, closes the slot handles, then calls `_release_records`. The record is read only when the nonblocking shared lock fails with errno EAGAIN or EWOULDBLOCK. A successful lock, a failed open, or any other lock error returns unknown.
