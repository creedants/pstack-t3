- When `--selection-only` and `--batch-dir DIR` are both set, the script creates `DIR` and does not archive. When at least one id is selected, it writes those ids in `--selection-only` order to `DIR/batch-1.txt`, `DIR/batch-2.txt`, and so on, at most `--batch-size` ids per file (default 140), one id per line with no quoting, and it prints one line per file as the path, a tab, and the count. When no id is selected it writes no file and prints nothing. An existing path is an error and nothing is written. Without `--selection-only`, `--batch-dir` exits non-zero, writes nothing, and archives nothing. This path does not read `T3_CODE_MCP_AUTHORIZATION`.
