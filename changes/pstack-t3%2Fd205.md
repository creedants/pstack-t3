- `scripts/run_tests.py --part i/n` runs part i of n. Modules are sorted by descending test count and then by name, tests in a module by id, and part i is every test whose index in that sequence leaves remainder i - 1 when divided by n. A value that is not i/n, an n below 1, an i outside 1 to n, and a part with no test are refused with exit 2. A run that does not pass `--part` still runs every discovered test and exits by the same rules.
- CI runs `--part 1/4` through `--part 4/4` as jobs `part (3.10, k/4)` and `part (3.12, k/4)`. Jobs `test (3.10)` and `test (3.12)` run with `if: always()`, need the four part jobs of that version, and fail unless each of those jobs has result success. The generated-skills step runs on those two jobs only.
