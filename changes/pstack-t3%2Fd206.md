- `check_tree` reports library wording, machine values, and shared source when the tree contains `pstack-runtime/scripts/roles.py`. A tree without that file gets none of those findings. Library wording reports a string under `tests/` that contains `invalid choice`, `the following arguments are required`, `unrecognized arguments`, or `expected one argument`. A comment, a formal docstring, a string inside `assert_refused_choice`, and a string in `test_check.py` whose nearest function name starts with `test_library_wording` are not findings. A module-level constant in `test_check.py` is still checked, and so is a helper there whose name does not start with `test_library_wording`. Machine values report the home directory, user name, or host name of the identity `check_tree` reads for this machine when that value appears as a path or an address in `ops/` or `docs/operations.md`, and a missing `ops/t3-nightly-update.sh`, `ops/t3-archive-threads.py`, `ops/config.example`, or `docs/operations.md` is a finding. Shared source reports a missing `IGNORED`, `config_home`, or `new_file`, a missing file, source text of one of those names that differs between `t3/scripts/roles.py` and `scripts/install.py`, and a binding of one of those names that the static comparison cannot resolve.
- A function's shared source is the lines from its first decorator, or from the def line when it has none, through the last line `inspect.getblock` keeps. A blank line inside the function is kept. A blank line after that last line is dropped. A comment at column 0 after the function is dropped. An inline comment on the last statement and an indented comment after that statement stay in the text. A def, an async def, an assignment, an annotated assignment with a value, or an augmented assignment to `IGNORED`, `config_home`, or `new_file` inside `if`, `try`, `with`, `for`, `while`, or `match` at module level is a finding, and so is an augmented assignment to `IGNORED` in the module body. The finding says the static comparison cannot resolve that binding. A binding inside a function or class body is not a finding. The library-wording diagnostic says the string contains the argparse phrase. The formatting of argparse's choice list differs between Python 3.10 and 3.12.
