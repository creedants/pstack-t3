- `check_tree` reports library wording, machine values, and shared source when the tree contains `pstack-runtime/scripts/roles.py`. A tree without that file gets none of those findings. Library wording reports a string under `tests/` that contains `invalid choice`, `the following arguments are required`, `unrecognized arguments`, or `expected one argument`. A comment, a formal docstring, a string inside `assert_refused_choice`, and a string in `test_check.py` whose nearest function name starts with `test_library_wording` are not findings. A module-level constant in `test_check.py` is still checked, and so is a helper there whose name does not start with `test_library_wording`. Machine values report the home directory, user name, or host name of the identity `check_tree` reads for this machine when that text appears in `ops/` or `docs/operations.md`, and a missing `ops/t3-nightly-update.sh`, `ops/t3-archive-threads.py`, `ops/config.example`, or `docs/operations.md` is a finding. Shared source reports a missing `IGNORED`, `config_home`, or `new_file`, a missing file, and source text of one of those names that differs between `t3/scripts/roles.py` and `scripts/install.py`.
