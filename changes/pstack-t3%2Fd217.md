- A user name matches after a tilde, or after a name-class character and a slash, when the next character is outside the name class `A-Za-z0-9._-`. It matches as the only segment of an absolute path when the slash has no name-class character before it and the next character is neither a name-class character nor a slash. It matches before an at sign when the previous character is outside that class. It does not match as the first segment of a longer absolute path, so `</dev/null` is quiet for the user `dev` and `cd /root/foo` reports the home `/root` without the user `root`.
- A host label matches after an at sign or two slashes when the next character is outside the word class `A-Za-z0-9_-`. It matches before a colon and a digit when the previous character is outside that class. It matches before a dot and an alphanumeric when the previous character is outside that class and is not a slash, a dollar sign, or a double quote. The match is case insensitive and uses the first label. For the label `ops`, `"ops.conf"` does not match and `ping ops.lan` does. For the label `app`, `$APP.prev` does not match and `curl app:3773/x` does. For the label `config`, `ops/config.example` does not match, and `//config/share` and `see config.json` match.
