- `dish --thread` compares a non-empty id after `stored` cleans it. A padded id of the current worker writes no retirement, and the next unpadded command is accepted. A whitespace-only id stays raw, so it still clears that worker.
- The entry load drops its unique package and that package's children in a `finally` that covers the imports and `seam.bind`, then puts back any `brigade_lib` cache entries that were already there.
- On a sent-back item, `dish --state in-progress` keeps the current thread when that thread is the one open worker row started after the latest sent-back dish row and the id is not retired. A later queued or in-progress dish row clears that departure. A return from queued with no new thread clears the cell, and a non-empty cleared id is an earlier attempt. Repeating the kept id is not an earlier attempt. A restart that did not bind a new thread still clears the cell. `dish --thread` alone still leaves the state sent-back.
