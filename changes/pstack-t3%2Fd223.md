- The activity page reads `threads.tsv` with the same missing-file and malformed-line handling as its other tables. A thread row has eight cells. Each work item lists the rows for that item. ASCII digit attempts sort by their integer value, any other attempt sorts after those by its text, and rows with the same attempt keep their place in the file. A row shows the word attempt, the attempt text, the role, and the seat, dropping the role and the seat when the filter leaves them empty, then `open` or `ended`. A worker or a fix worker with an empty end cell is open, and every other row is ended. The HTML data element carries those phrases under `L` when any item has one, with the same escaping as its other strings, and the plain form prints each phrase under the item. A store with no `threads.tsv`, and a file that has only its header, draw no such lines.
