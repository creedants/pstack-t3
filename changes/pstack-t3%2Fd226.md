- `ticket add --from-report` treats a line whose stripped text starts with three or more tildes as a fence, the same way it treats a line whose stripped text starts with three or more backticks. The fence closes on a later line whose stripped text starts with three or more of that same character. A line whose text is only `---` inside the fence stays in that block, and a filed follow-up includes it in the summary. A line outside a fence whose text is only `---`, and the same line written as `- ---`, is still skipped.
