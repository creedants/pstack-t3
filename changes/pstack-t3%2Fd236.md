- The landing skill shows `slot --slots 2` taking 2 worker slots in one admission. A command that runs several heavy processes takes that many worker slots with `slot --slots N` in one admission, unless it is already inside a slot. With no `--slots` and no `--exclusive`, the count is one. A count above the governor's worker slots is refused and the command does not run, unless the command is already inside a slot. Without `--exclusive`, a count that is not a positive integer is refused before the command runs, and `--slots` with `--exclusive` is refused before the command runs.
