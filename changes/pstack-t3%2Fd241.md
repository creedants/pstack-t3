- `Sandbox.run` starts `ops/t3-archive-threads.py` through `tests.in_process.invoke`. `run` in `tests/test_release.py` starts `scripts/release.py` through `invoke`. `CheckoutCase.sync` starts `scripts/sync_upstream.py` through `invoke`. Setting `PSTACK_TEST_REAL_PROCESS` to `1` starts a real interpreter for those calls. Bash, git, and ssh-keygen in these tests stay `subprocess.run`.
- `checkout_import` sets `tempfile.tempdir` to `None` and removes each loaded module whose `__file__` is a different path from a sibling `*.py` file with an identifier stem. `CheckoutCase.sync` calls it around `invoke`, and the context manager puts the saved tempdir and those modules back. `CheckTest.test_each_row_names_the_file_the_build_renders` still runs `sys.executable -B -c` and still compares the last line of each rendered file with the checkout source, or expects no file when the mapped source is `None`.
- `SHARD_SIZE` in `scripts/run_tests.py` is 20. `BuildShardsTest` expects each shard to hold 1 to 20 tests. `test_25_tests_with_one_id_run_once_each_in_2_shards` expects 25 tests in 2 shards.
