- A pending, running, or waiting row in `orchestration_v2_projection_nodes` does not add its thread id to the live set when its run id is a run whose status is interrupted, cancelled, or failed. A provider-native row in `orchestration_v2_projection_subagents` whose run id is a run in one of those statuses does not add its thread id or its child thread id. A pending, running, or waiting node row with a null run id still adds its thread id. A provider-native row with status pending, running, or waiting and a null run id still adds its thread id and its child thread id. A pending, running, or waiting node row whose run status is running, queued, starting, preparing, or waiting still adds its thread id. A provider-native row in those statuses whose run status is one of those still adds its thread id and its child thread id. A run whose status is running, queued, starting, preparing, or waiting still adds its thread id.
