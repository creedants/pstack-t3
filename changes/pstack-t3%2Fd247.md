- `scripts/check.py` gains `guide_count_findings`, which `check_tree` calls with its `guide` flag when the tree holds `pstack-runtime/scripts/roles.py`. The build keeps that flag and `main` passes `guide=not argv`, so the build and a bare `python3 scripts/check.py` run the rule, and an explicit tree argument does not.
- The rule reports a doctor count quoted in `docs/guide.md` whose two numbers differ, or whose first number differs from the number of directories directly in the tree that hold a `SKILL.md`, which is the set `skill_names()` in `scripts/install.py` reads. A guide that quotes no doctor count is reported too.
- `tests/test_check.py` covers a matching count, a stale count, a quote whose two numbers differ, a guide that quotes no count, a guide that cannot be read, an explicit tree argument that holds `pstack-runtime/scripts/roles.py` and prints no guide finding, and the four rendered-tree cases that now point `GUIDE_PATH` at a guide that matches the tree.
