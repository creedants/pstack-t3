- A pending, running, or waiting row in `orchestration_v2_projection_nodes` does not add its thread id to the live set when its run id is a run whose status is interrupted, cancelled, failed, or rolled back. A row in `orchestration_v2_projection_subagents` whose origin is `provider_native` and whose status is pending, running, or waiting does not add its thread id or its child thread id when its run id is a run whose status is interrupted, cancelled, failed, or rolled back. A node row or provider-native row with a null run id still adds its thread id, and a provider-native row with a null run id still adds its child thread id. A node row or provider-native row whose run status is running, queued, starting, preparing, or waiting still adds the same thread ids.
