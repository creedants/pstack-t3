- `_clear` also removes the temporary record files a crashed holder left in governor/holds, and it does so while this process's slot flocks are still held.
- A name in governor/holds that ends in .tmp and is not this process's own record is removed unless a nonblocking exclusive flock on a read-only open succeeds on it, because a writer locks the file it opened before it writes the record and holds the lock until it lets the slot go. A failed open and any lock error leave the name, since neither proves the writer is gone.
- `pr_body` appends the work item's kind and goal line after one blank line, and returns that line alone when the body holds no text but whitespace. The body comes from the submitted `--body-file` or from the reviewed commit's message, and the body's trailing whitespace is dropped before the line is appended.
- The line reads `Kind: <kind>. Goal: <name>`. One part prints alone, and nothing new prints when the item has neither.
- The kind prints only when it is one of feature, fix, polish, upkeep, and study. The goal prints as the name its id has in the store's goals.tsv, and a name that is empty or holds a carriage return or a line feed prints no goal part, as does a goal id with no row there.
- The store root is $BRIGADE_STORE when that variable holds a value, else `state_home()/brigade`. A store is a directory two levels under that root. The store read is the one whose `restaurant.json` records a projectRoot that resolves to the same directory as `store.repo`. An exception to that match is a store with no record at all, which is read only when it is the one store directory under the root and it holds a dishes.tsv. A store whose record is unreadable, is not a JSON object, or holds `role` of `admin` is skipped, and so is one with no dishes.tsv reachable.
- The work item row is the last row of dishes.tsv whose `branch` cell equals the entry's branch, and every cell is read by its header name. A table with a line wider than its header holds no rows at all.
- A missing store root, a record or table name that cannot be reached, an unreadable record or table, a row with more cells than its header, and an empty result each return the body unchanged and never raise.
- `foreign_author` still scans every line of the body `pr_body` returns for CREDIT_LINE, so no line of text a caller submitted is lost. The body's trailing whitespace is dropped before the line is appended.
- `_close_live_owners` skips an object whose fileno lookup or fileno call raises a BaseException other than KeyboardInterrupt, and it raises KeyboardInterrupt on. Such an object never reaches the owner list, so it is not closed. Its `depth` helper stops walking the file chain of an owner it already accepted when that walk raises such an exception, and that owner is still closed.
