- brigade: `edits apply <item> --report <review report> --from <reviewed sha> --branch <new branch>` applies a pass-with-edits review's edits with no worker. It refuses the whole report with one line when an old text does not occur exactly once in its file at the reviewed commit, when a path is generated or is not a regular file there, or when the applied change is over the small-fix cap. Otherwise it creates a git worktree and the branch from the reviewed commit, applies the edits, runs the landing contract's setup and the build command, commits once, and prints the head and the worktree path. A failure removes the worktree and the branch. It never pushes and records no verdict, so the coordinator still runs `edits verify`, the tests, and `pass record`, and launches a fresh fix worker only when it refuses or fails
