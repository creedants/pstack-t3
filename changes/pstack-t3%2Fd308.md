- kind feature
- `check_tree` in `scripts/check.py` gains `fragment_findings`. In every `.md` file under the built `brigade/`, `brigade-admin/`, and `pstack-runtime/` skill directories, at any depth, each markdown link with a `#fragment` whose target is a `.md` file in the tree must name a heading in that target, by the slug rule `heading_slug` uses. `scripts/check.py` copies that slug function instead of importing the tests. An in-file `(#x)` link is checked against the file that holds it.
- A shared fence scanner hides fenced lines. It tracks marker character and opening length. It recognizes tilde and backtick fences. It closes only on a matching fence of sufficient length. It allows up to three spaces indent. An unclosed fence hides the rest of the file. Code spans are removed before link extraction. An optional title after the destination is recognized and excluded from the destination. Original line numbers are preserved.
- Anchors are allocated in document order. The first heading keeps its slug. A duplicate appends `-1`, then `-2`, until the anchor is free. A heading whose natural slug is taken gets the next free suffix. A link with no fragment, a link inside a fenced code block or code span, a link whose path does not resolve, a link whose target is not a `.md` file, a link whose target is outside the tree, and a link into a vendor-derived skill are not checked. A skill is vendor-derived when its directory name is a directory name under `vendor/pstack/skills`, because `vendor/pstack/` cannot be edited.
- A finding names the holding file, the line, the fragment, and the target file, and fails the build. An empty list means no checked fragment link failed. The check reads 169 fragment links on the current tree and reports none of them.
- `tests/test_check.py` gains `FragmentCheckTest` cases for tilde fences, longer fences hiding inner markers, headings inside tilde fences, code spans, titled links, duplicate anchors, and suffix collisions, plus the existing on-demand, in-file, vendor, fence, and `check_tree` cases.
