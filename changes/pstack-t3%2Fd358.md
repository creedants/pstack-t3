- `t3/added/brigade/scripts/activity.py` folds earlier attempts. For each work item not finished per `finished(group)`, ledger lines at the max attempt rank stay current, and an earlier ledger row whose thread is a shown live row of an earlier-worker family or one of its shown ancestors stays current too. A depth-0 row labelled `earlier worker` marks itself and following depth greater than 0 rows earlier until the next depth-0 row, except each live row and its ancestors to the depth-0 root, which stay shown. The summary counts each earlier ledger thread that an earlier-worker lane also holds once under its ledger role, and each other earlier ledger row once under its role, and each other earlier row once under its lane label, in `ROLES` order then unknown sorted. Attempts come from earlier ledger ranks only, so a fold of lanes alone states counts plus state. State is `all ended`, `all open`, or `N open plus M ended`. Folded rows of a drawn group expand on click to the shown rows. The details list each folded ledger line that the byte budget leaves room for, and the page note counts the rest. No earlier rank and no earlier-worker family keeps all lines current with an empty fold.
- `t3/added/brigade/scripts/activity.py --live-page` takes an optional `ORIGIN`. With an empty value it polls `http://127.0.0.1:48731`. With a non-empty value it polls `ORIGIN` plus `/activity/<token>`. It accepts an `http://` or `https://` URL with a host and no userinfo, path, query, or fragment. Any other non-empty value is refused with `activity: --live-page takes an http:// or https:// origin with no userinfo, path, query, or fragment; pass one such as https://home.example.ts.net:48731, or omit it to use http://127.0.0.1:48731`.
- `t3/added/brigade/scripts/activity.py` runs one visibility application for group state and attempt state in the live wrapper. In the live wrapper, the attempt toggle updates the row class and reruns the group application, which sets inline display from group and attempt state. The static document's attempt toggle flips the `earlier` class on each folded row.
- `t3/added/brigade/scripts/activity.py` keeps earlier attempt membership on synthesized summary rows. A summary row is earlier when every row it folds is earlier, so a byte-budget fold keeps an all-earlier family inside the attempt fold; a fold that includes a shown row stays visible.
- `t3/added/brigade/scripts/activity.py` bounds fold summaries to their attempt counts when no attempt line prefix fits the byte budget and the page has at least one attempt line. Counts and state stay exact, and no lane is dropped.
- `tests/test_activity.py` covers an item with three attempts showing current rows, one count line with per-role counts, and full rows for expansion. It covers a single-attempt item rendering with no fold. It covers `--live-page` with a valid `https` origin, the default, and refusal of an origin with a path, a query, and a non-`http` scheme. It locks `ROLES` to the store role tuple.
