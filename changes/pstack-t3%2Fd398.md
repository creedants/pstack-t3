- The queue no longer hard-codes a generated path or a rebuild command, so a repository with no generated config lands a hand-written `skills/` change as ordinary source with no rebuild.
- With no generated paths the queue never refuses a change as generated-only, never runs `git rm` or `git clean` for a generated path, and never rebuilds.
- With generated paths and no rebuild command the queue refuses a change that touches only those paths and names the missing command.
- A rerun keeps a stored `generated` and `rebuild` whose flag is omitted; an empty value clears either; `init` refuses an absolute path, a path with a `.`, `..`, or empty component, and an empty entry in the list.
- `init` and a repo-level `status` print `generated` and `rebuild` when the contract holds either.
