- `roles.py` removes every built-in model pick. An unset role resolves to `inherit` when the exclude list allows the inherited parent, and `review backups` stays `unset`.
- `roles.py` adds the optional `exclude` and `backups` keys. `exclude` refuses a seat by model-id glob, declared option, provider glob, role name, or a combination; every entry is an object and a string entry is refused with a message that names the `exclude` key. `backups` lists the seats `roles.py backup` tries in order.
- `roles.py` checks `exclude` on the final target after the budget cap, except the accepted `--resume` original-seat exception, validates `backups` seats and their options against the catalog, validates an `exclude` rule's options against the catalog, and keeps a `backups` candidate's declared options when it relaunches.
- `roles.py backup` takes the failed seat's level only when a candidate names no effort option, so a candidate's declared special effort, such as `ultrathink`, is not overwritten by the failed seat; the budget still applies to it.
- `roles.py backup` skips a backup candidate the `exclude` list refuses and tries the next one; the `backup` preflight no longer treats an excluded candidate as a fatal problem.
- `roles.py` keeps the Cursor `skill tests` rule, matched by `driverKind`.
