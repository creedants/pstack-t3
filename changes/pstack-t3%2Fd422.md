- `pass record` skips a line of a report's `## Threads` section when it is plain prose, that is when it starts after any leading whitespace with no list marker, is no heading, holds no backticked thread id, and names no child role, and refuses by its number every other line that is not one item of the form - <role> `<thread id>` <seat>. A list marker is a hyphen, an asterisk, a plus, a bullet, or a number followed by a dot or a closing parenthesis. A backticked thread id is a backticked value holding a colon.
