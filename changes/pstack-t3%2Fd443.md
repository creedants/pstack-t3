- kind feature
- `brigade.py set --change-note-dir <dir>` records the repository-relative directory holding one change-note fragment per branch, and an empty value clears it. A store with the key set leases `<dir>/<branch>.md` with `%` as `%25` and `/` as `%2F` on `fire`, `watch` rechecks, and `dish --branch`, and the affected picker skips paths under it. A store without the key leases no fragment and skips nothing for change notes.
- `t3/added/brigade/scripts/brigade_lib/store.py` `change_note_dir` reads a missing key and an empty string both as unset, and refuses an absolute path, `..`, a comma, whitespace, or a non-string through `refuse_setting`, so a malformed stored value refuses any `set` and any `affected` run with nothing written and no lease claimed.
- `tests/brigade/test_leases.py` pins the unset default leasing no fragment, a set key leasing the encoded fragment under `changes` and `notes/sub` with `%` encoded before `/`, and malformed flag and stored values refused with the store byte-identical.
