- kind feature
- `brigade.py set --change-note-dir <dir>` records the repository-relative directory holding one change-note fragment per branch, and an empty value clears it. A store with the key set leases `<dir>/<branch>.md` with `%` as `%25` and `/` as `%2F` on `fire`, `watch` rechecks, and `dish --branch` prints the commands that cover the new fragment and claims nothing itself. The affected picker skips paths under it when the store has an affectedTests layout. A store without the key leases no fragment and skips nothing for change notes.
- `t3/added/brigade/scripts/brigade_lib/store.py` `change_note_dir` reads a missing key and an empty string both as unset, and refuses an absolute path, `..`, a comma, whitespace, or a non-string through `refuse_setting`, so a malformed stored value refuses any `set`, the `affected` command for that project root, and a brief affected check for its own store, with nothing written and no lease claimed.
- `tests/brigade/test_leases.py` pins the unset default leasing no fragment, a set key leasing the encoded fragment under `changes` and `notes/sub` with `%` encoded before `/`, and malformed flag and stored values refused with the store byte-identical.
- `tests/brigade/test_items.py`, `tests/brigade/test_tickets.py`, and `tests/brigade/test_wake.py` set `changeNoteDir` to `changes` where they assert the encoded fragment. `tests/brigade/test_affected.py` sets the key so the changes skip is exercised. `tests/brigade/test_briefs.py` renames the stale changelog test to `test_fire_with_change_note_dir_leases_the_encoded_fragment_and_dish_records_a_new_lease`.
