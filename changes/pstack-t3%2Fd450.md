- `watch` prints `trunk CI failing since <since>: <workflow> <url>` when the newest completed run in the last 100 runs failed. When the failure streak ends inside those 100, `<since>` is the oldest consecutive completed failure. When the window holds 100 runs and every fetched completed run from the newest completed run to the end of the window failed, `<since>` is `before <createdAt of the oldest fetched run>` and the start is unknown. It stores red so the cues still fire. When the window holds no completed run, it prints `cannot see trunk CI: no completed run in the last 100 runs` and stores unseen. It prints `cannot see trunk CI: <reason>` when the trunk state is unseen. It prints one trunk line while it sees a red or unseen remote mode trunk. It stays silent with no contract or in local mode. It writes one `trunk` log row only on change.
- `next liveness` and `next merge` owe red trunk See cues while the stored trunk stays red. A store that does not report to an executive admin replies yes at every-turn, milestones, and digest. No cue when the stored trunk is green or unseen or unknown.
