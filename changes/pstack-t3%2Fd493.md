- `brigade affected` maps a file under a private package directory `<pkg>/_<name>/` that its facade `<pkg>/<name>.py` imports directly or that `<pkg>/_<name>/__init__.py` imports with the tests that select that facade, when an import resolution lands the facade file, when an import whose loader is that facade and whose file exists lands `<pkg>/_<name>/__init__.py`, or when a load ref names the facade. That landing edge's imported name, or for a `*` or plain `import` edge the last segment of its module, must not start with `test_` for the first two cases to expand into the package's members. The facade's own member imports and the load-ref case have no imported-name check. The direct-import half takes a facade that sits in a directory and whose name is neither `__init__` nor `_` nor `test_`-prefixed. In the load-ref case the hop from the loaded facade reaches the members of `<pkg>/_<name>/` that the facade or its `__init__.py` imports, with no separate resolution to `<pkg>/_<name>/__init__.py`. Files under that directory which neither the facade nor `<pkg>/_<name>/__init__.py` imports gain no mapping from this rule.
- A file under `<pkg>/_<name>/` that the file at `<pkg>/<name>.py` or `<pkg>/_<name>/__init__.py` imports from under that directory, and that already maps the tests that select it, keeps those tests and also maps every test the table at that point maps to `<pkg>/<name>.py`, through imports, load refs, literal pins, or this same pass on another facade. When the table maps no test to that path, nothing changes.
