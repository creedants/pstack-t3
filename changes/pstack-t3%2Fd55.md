- A refused `brigade.py fire` records the paths and branch it was given, and `watch` says whether a lease, the repository cap, or the worker cap still blocks it, with the number of workers that are running. The unblocked line is a shell-quoted `fire` command that includes `--branch` when one was recorded. `fire` leases `changes/<branch>.md` for the branch that attempt will use, including when `watch` rechecks a blocked ticket. `open --workers` and `set --workers` cap how many items can be in progress or in review, and a missing value reads as 2. `dish --lease` and `dish --paths` record a lease claimed again. A release that fails names the lease and the landing queue's diagnostic, and a failed lease check keeps that diagnostic.
