- In merge mode, `land.py init` reads `gh repo view --json mergeCommitAllowed,squashMergeAllowed,rebaseMergeAllowed`. With no `--merge-method` it stores the only allowed method, keeps merge when that method is still allowed, and stores squash when merge is not. It refuses a method the repository disallows and names the allowed methods. When `gh` cannot answer, it stores merge, or the method you passed. `land.py mode --merge-method` can change while entries are queued, landing, or awaiting merge. Changing the mode still needs an empty queue. A pause caused by a refused merge method names `land.py mode merge --merge-method` with an allowed method, then `land.py resume`. One busy entry reads as `1 entry is`.
