- `brigade.py dish --state dropped` returns the dropped item's assigned tickets to waiting, with a log row naming the item, so their refs and intake source no longer stay held. `ticket list` and `walk` count a ticket blocked only while `watch`'s recheck says the block still holds, and `fire` and `watch` check the worker cap before the lease, so they name the same reason. `hang --attempt <n>` records a run an earlier attempt left open. `dish --branch` on an item with a lease leases the new branch's changelog fragment.
