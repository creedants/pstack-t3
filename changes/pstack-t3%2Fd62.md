- brigade: an optional executive admin store per repository. `open --admin` claims `<project>/.admin`, which refuses `fire`, `brief`, `dish`, `pass`, and `watch`. `request` publishes a durable request into a coordinator's inbox and `request --republish` restores one a crash left unwritten, `inbox take` and `inbox done` act on it, and `ticket add --request` files one ticket per request. `rule` records, overrules, ends, and lists rulings in `rulings.tsv`. `sync` relays every coordinator's new `log.tsv` rows once through one locked snapshot reader. The admin's thread is replaced only by `set --thread --replace --expect`, and a `recovering:` claim needs `--stopped`. `set --reports-to` records the thread a coordinator reports to, `status` prints the thread first, and `walk` lists the admin first.
