- kind feature
- In light mode a coordinator gets one read-only look-back a week in place of the scheduled reflect it does not run. `set --look-back <days>`, default 7, holds the interval, and `0` or `""` turns it off, so every store gets one until it is turned off
- `next evening` prints one `run look-back` cue while the effective mode is light, the setting is on, the interval since the last recorded look-back has passed, and at least one review round was recorded since then. A full-mode coordinator, an evening with nothing new, and an off setting add no cue
- `look-back` writes `look-backs/L<n>.md` and `look-backs/L<n>.json` under the store and prints the brief's path. The brief lists the rounds since the last look-back, newest 50 at most with the cap named when it applies, each with its item, verdict, send-back reason, report file, and that item's worker and reviewer threads. It names the six categories, the proposal file format, and the rules, and it copies no report body. A second run while a brief has no stamp rewrites that brief at the newer moment instead of writing another, so `--record` stamps one brief
- `look-back --record <file>` stamps the run only when every proposal names a category, a fix type, a change, and evidence this store holds, which is a report file under `reports/` or a thread the brief lists. A refused proposal writes nothing, so the cue stays. `--record --none --reason "<one line>"` stamps a look-back that held nothing usable, and a second record for one brief stamps nothing
- `close` gains a `## Look-back` section listing the proposals recorded since the last report, in plain words, with the file that holds them. An off setting and an empty look-back print no section. Proposals are not tickets and not decisions, and only the owner's yes turns one into a ticket
- The brief has the reader check the repository's own check command and CI first, so a check that exists and is not connected is the finding. A mechanical mistake is proposed as a check, and only a judgement call is proposed as a reviewer rule
