- Light mode now changes seats. `roles.py show` and `bounded-seat` take `--brief-mode`, `--session-mode`, and `--coordinator-mode`, resolve the mode in the order brief, session, coordinator, project, user, `full`, and cap reasoning at `medium` under light when the budget is `default`. An explicit budget still wins, and a capped model still runs only for skill tests. `show` warns on stderr when the cap could not reach an `inherit` seat. A new `roles.py mode` prints a brief's `Playbook:`, `Mode:`, `Mode source:`, `Attempt:`, and `Waived by mode:` lines. It moves an item to `full` when a lease covers a path in the project's `escalate` list, at the second send-back, or for a recorded reason, and reads waivers from `LIGHT_WAIVERS`. A stored escalate entry that normalizes to the repository root stays in the file, and roles.py mode does not treat it as a match for a tracked file.
