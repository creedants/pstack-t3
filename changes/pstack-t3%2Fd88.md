- roles.py never returns a fast Grok seat. A fast model id is skipped, including an inherited parent, and that provider's first pickable model is used instead. A Grok model that declares `fastMode` is pinned false, and an inherited parent in that case becomes an explicit seat. A roles-file seat that names a fast id or `fastMode` true is skipped on show, and validate and write refuse it even with `--force`. When every configured seat for a role is skipped, that role uses its built-in default.
