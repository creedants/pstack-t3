- Each checkout records the links it installs. Uninstall from that checkout removes those links, including links another checkout moved aside, and restores what they covered. A link you point somewhere else keeps its record, and uninstall removes it if you point it back. Records stay when a checkout is missing. Older installers keep using the same manifest and can still remove what they installed. The installer still never deletes a file it did not create. Uninstall never restores an entry over one that took its place. It keeps the backup and says so. It also keeps a backup that was replaced or changed after uninstall read it. A backup on another filesystem is copied beside its path and moved in the same way. Uninstall restores the entry it held open, not whatever the backup's path names later. An entry that takes that path during uninstall is neither restored nor deleted. Uninstall leaves it there, or prints where it is kept.
