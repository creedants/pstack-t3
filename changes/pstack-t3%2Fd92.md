- `scripts/install.py` records which checkout created each installed link, in `install-manifest-v2.json`. Uninstall from one checkout removes only links that checkout created and that still point where it wrote them. A link another checkout's `--replace` moved aside comes back with its owner recorded, so the first checkout can still remove it. A repointed, alias-spelled, or lookalike link, and a link from a deleted checkout, is forgotten and left on disk. `--dry-run` prints the counts of the same plan the real run executes. Rows written by older installers migrate on the next run. The installer still never deletes a file it did not create.
