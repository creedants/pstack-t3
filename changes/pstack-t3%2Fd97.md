- A stopped or failed install or uninstall no longer strands an entry. Uninstall moves each entry through a `.pstack-t3-*` directory beside its path. When a step fails there, the `skipped` line now ends with the path the entry is kept at. Every later install or uninstall looks in those directories beside the skills directories and backups it manages. It returns an entry to its recorded path, without overwriting, when a backup row or this checkout's owner record proves the path. It leaves any other entry where it is and prints its location. It removes empty directories and spare hard links. A copy in progress sits in a `.pstack-t3-scrap-*` directory and is never placed. The state lock descriptor is closed when the unlock fails.
