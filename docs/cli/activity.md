# activity.py

Source: `t3/added/brigade/scripts/activity.py`

Generated by `scripts/cli_reference.py` from this script's own argparse definition, so it never drifts. The other scripts are listed in the [command-line reference](README.md).

A usage line shows a required flag bare and an optional one in brackets. `[flags]` stands for the flags of the command before it, listed in that command's section.

```text
activity.py [--at AT] [--hours HOURS] [--text] [--out OUT] [--max-bytes MAX_BYTES] [--t3-home T3_HOME] [--serve [PORT]] [--live-page [ORIGIN]]
```

Show what one brigade coordinator's agents and sub-agents are doing, as one HTML page.

Opens the coordinator's store and T3 Code's state database read-only. Prints one self-contained HTML document, or plain lines with --text, or writes either to the file --out names. The output and the newline after it take at most --max-bytes bytes. Output that would take more is shortened. It counts the agents, work items, attempt lines, and pull request links it leaves out, and it ends each string it cuts with an ellipsis.

Every string a page emits passes one filter after its parts are joined. In the HTML document that is each string of the data element. In the plain form it is each line. The filter drops each character UTF-8 cannot hold and writes each control character, line separator, and paragraph separator as a space. It then removes each word that holds private text and repeats until no word does. The first word that stays follows the spaces that start the string, and each later word that stays follows the spaces that stood before it. A string that still holds private text after 8 passes is emitted empty. The filter reads each string as written, as the HTML document writes it, and both with their percent escapes decoded once and twice.

Private text is an identifier or a path this run read, as stored and with its own percent escapes decoded once and twice. Its control characters are read as spaces, and it is compared with each character of both texts in lower case when that is one character. The identifiers are the thread ids, the sub-agent ids, and the work items' task values in the store and in T3's turn and sub-agent rows. An identifier that reads as ordinary words is not private text. That is at most 48 characters of letters and digits in runs joined by single spaces, dots, or hyphens, where a run with both letters and digits is at most 8 characters. A form of spaces only is not private text either. Neither is an identifier form of fewer than 4 characters. A non-empty thread-column value is read as stored and with its percent escapes decoded once and twice, and each of those forms is also read without the spaces that start and end it. A reading that holds a character other than a space is private text even when it reads as ordinary words. A form of 4 or more characters is private text anywhere in a word. A shorter form is private text only where no letter, digit, underscore, or hyphen stands directly before or after it. The paths are the store's directory, the project root the store records, T3 Code's base directory and database, the home directory, and the --out file. Each path is read as an absolute path, with symbolic links followed, and as given when that is absolute. A path form of 4 or more characters is private text anywhere in a word. A path form of fewer than 4 characters is read without the slashes that end it, and a form of slashes only is read as one slash. It is private text only as a whole word. That word starts with a slash that starts the string or follows one of the characters the last path shape below can follow, and it ends before the next space, quotation mark, or backtick. The word is also the form when it is the form before one or more of a slash, a closing round, square, curly, or angle bracket, and the marks . , ; : ! ? \|.

Private text is also text of one of these shapes, with upper and lower case letters read alike. A UUID. One of mcp, thread, node, run, task, run-attempt, provider-turn, provider-session, context-transfer, and context-handoff anywhere in a word, then a colon, then a letter, a digit, an underscore, or a percent sign. An email address, which is an at sign between a local part and a domain. The domain is a name that holds a dot before two or more letters. Or it is square brackets around four numbers of 1 to 3 digits joined by dots, or around `IPv6:` and one or more hexadecimal digits, colons, and dots. The local part is 1 to 62 characters other than a straight double quotation mark between two such marks. Or it is 1 to 62 characters between two such marks, read from the left with a backslash and the character after it as a pair, where the last pair ends before the closing mark and each such mark among the characters is the second character of a pair. Or it ends in a character other than a space, an at sign, a round or square bracket, an angle bracket, a straight quotation mark, a comma, a semicolon, a colon, or an ampersand. `file:` with no letter or digit before it, then a letter, a digit, an underscore, a slash, a backslash, a dot, a tilde, or a percent sign. A drive path, which is a letter from a to z with no letter or digit before it, then a colon, then a slash or a backslash. A path that starts the string or follows a space, a quotation mark, a backtick, an opening bracket, an angle bracket, an equals sign, a colon, a comma, a semicolon, or a vertical bar. Such a path starts with a slash before a character other than a space, a slash, a quotation mark, or a backtick, and it holds a second slash with no space, quotation mark, or backtick before it and a character other than those after it. It can start with two or more slashes instead when no colon stands before them. Or it starts with a tilde before a slash or a backslash, with a tilde and a name that starts with a letter or an underscore before one, with $HOME or ${HOME} before one, or with two backslashes before a letter, a digit, an underscore, or a dot. A path after an opening quotation mark or a backtick is private text up to the mark that closes it. Any other path, and a path with no mark that closes it, is private text to the end of its word and through each next word that holds a slash or a backslash and does not start with a slash.

Private text is also the request name of a delegated task when that name holds a hyphen. The request names are the text after the last `delegate-task:` of each identifier this run read, with the identifier's percent escapes decoded once and without the spaces that start and end that text. A name that is runs of letters and digits joined by single hyphens is private text only as a whole such run, compared in lower case as an identifier is. A longer such run that holds the name is not the name. Neither is the name after a slash that starts the string or follows one of the characters the last path shape above can follow, such as /code-review. Any other name with a hyphen is read as it is and with its percent escapes decoded once and twice, each form without the spaces that start and end it. It is compared as a path this run read is. A form of 4 or more characters is private text anywhere in a word. A form of fewer than 4 characters is private text only where no letter, digit, underscore, or hyphen stands directly before or after it. A request name with no hyphen is not private text.

The filter removes a word for no other reason. The filter leaves a work item id, a summary, a title, the store's name, and a model name as they are unless they hold private text. It leaves a relative path such as src/a.py. It leaves a word of one segment that starts with a slash, such as /review, unless it holds private text. A delegated task's own request name of two or more hyphen-separated parts is split into words for its label. A pull request link is printed only as https://host/owner/repository/pull/number. Userinfo, a query, and a fragment are dropped. A work item on the page whose nonblank pull request value cannot be converted to such an address, or whose address the filter would change, has no link and is counted in a note. Different work items can print the same id, summary, state, and link. Each work item that is in flight or has an agent in the window is still listed or counted as its own work item.

--serve runs a local HTTP server on 127.0.0.1 for this store's page and prints its token address. --live-page prints the wrapper that polls the live server for html_render at the given address plus /activity/\<token>. The address defaults to http://127.0.0.1:48731. It accepts an origin such as https://home.example.ts.net:48731. The token lives in activity-token under the store directory.
