## land.py times

```text
land.py [flags] times [--last N] [--holder PREFIX] [--json]
```

report submit-to-landed minutes for the last N landed entries, one line per entry then a summary line. A line holds the entry's id, holder, PR, and minutes to one decimal, and the PR prints - when the entry has none. The summary line is n=\<count> median=\<m> p90=\<m> max=\<m> skipped=\<k>, where median and p90 are the nearest-rank 50th and 90th percentiles. An entry in state landed with no landed log row is not a line and is counted in skipped, even outside the --last window. --holder counts only that holder's entries. With nothing landed the three statistics print - and the command exits 0

| Argument | Required | Choices | Default | Help |
| --- | --- | --- | --- | --- |
| `--last N` |  |  | `30` | report at most this many of the most recently landed entries (default: 30) |
| `--holder PREFIX` |  |  |  | report this holder's entries; a value ending in / matches every holder under it |
| `--json` |  |  |  | print one JSON object instead of the lines; it holds entries, n, median, p90, max, and skipped, an empty PR is null, and the statistics are null when nothing landed |
