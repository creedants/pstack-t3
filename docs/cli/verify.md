Read-only checks of mesh evidence, raw T3 exports, and actual Git objects.

Run ``python -m pstack_mesh.verify --db PATH [--exports DIRECTORY]``. Exit codes are 0 for PASS, 1 for ISSUES, and 2 for BLOCKED. This checks recorded evidence; it cannot attest exporter authenticity or prove a model's internal memory.
