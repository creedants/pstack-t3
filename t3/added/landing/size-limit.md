## File size limit

Agent-written files stay small enough to review. Tokens equal bytes divided by 4 with integer division. The limit is 5000 tokens per file unless --max-file-tokens or the baseline maxFileTokens sets another maximum. The queue judges only while the contract sets a maximum or the trunk tip baseline explicitly opts in with enabled true. A baseline filename alone never turns the queue or bridge limit on.

The committed size-baseline.json names the allowance of each larger file. An entry is a token count or an object `{"relativeTo": "<repo-relative path>", "margin": <tokens>}`. A relative entry's allowance is the reference file's tokens plus the margin. The reference is read from the same source as the judged file: the worktree for `check.py` and `land.py size`, the index for `--staged`, and the candidate commit for the queue's check. The reference counts even when a skip entry covers it. In the worktree a symlinked file reads as the file it points to, as its size map does. check.py does not follow symlinked directories, so it reads a reference behind one as missing. A missing reference, or one that is not a regular file in that source, gives the entry no allowance and the over-limit line says the reference is missing. An object with other keys, a margin that is not a non-negative integer, or a reference that is absolute, holds a `..` component, or names the entry's own path makes the baseline invalid. An over-limit line for a relative entry whose reference exists names the reference path, its tokens, and the margin. The contract points at that file with sizeBaseline and may set the maximum with sizeMaxTokens, which overrides the baseline maxFileTokens. The queue reads the baseline from the actual trunk tip for every entry in a batch, not the integration head, and judges the files changed since the trunk tip at land time. Submit never judges sizes. A size violation bounces the entry with one line per over-limit file naming the path, the tokens, the allowance or the missing reference, and the split step. While the limit is on the queue refuses any entry that weakens trusted policy by raising an allowance, adding a grandfathered file above the effective maximum, raising the maximum, widening skips, or removing the baseline. The queue also refuses adding a relative entry, changing an entry between a token count and a relative allowance, changing a reference path, raising a margin, and removing a relative entry. Lowering a margin with the same reference lands. A contract maximum with no trunk baseline is trusted policy with default exclusions and no allowances. A first baseline is compared against it. Removing a below-maximum integer allowance raises it and is refused. Removing an above-maximum integer allowance lowers it and lands. Lowering an integer allowance, the maximum, or the skip list in isolation is always allowed. The queue fails closed when trusted policy is on but the size-baseline.json at the trunk tip exists and is not a valid baseline.

Turn the limit on with `python3 <skills>/landing/scripts/land.py --repo <checkout> init --trunk main --mode <mode> --max-file-tokens 5000`. A rerun without the flags keeps the stored values. `land.py status` names the limit while the contract sets one. With the limit off, `status` and `status --json` output matches the output before the limit existed. In this repository, keep every current contract value after merge with `python3 skills/landing/scripts/land.py --repo <checkout> init --trunk main --mode merge --max-file-tokens 5000`.

Judge work with `land.py size`. The default judges changed worktree files. `--staged` judges staged files from the index. `--all` judges tracked and unignored untracked files. The first run seeds the baseline with each counted over-limit file at its current tokens. When the contract sets a maximum or `--staged` runs, seeding reads committed HEAD and never reads staged content. With no limit set, initial seeding reads the worktree and writes a baseline without `enabled`. `--shrink` lowers stored allowances that fell and never raises one. `--shrink` and seeding never write or change a relative entry. It uses the effective maximum. `--baseline` reads and writes another file instead of the contract one. `check.py` resolves trusted policy from the merge-base before the worktree candidate. A missing or disabled candidate never disables trusted policy. It fails closed when trusted policy is on but the base cannot be read. It ignores an incidental baseline while the limit is off. The hook resolves trusted policy from HEAD and the contract. While trusted policy is on or HEAD holds a valid baseline, a baseline missing from the index counts as missing candidate policy and never falls back to the worktree file. It refuses staged removal while trusted policy is on and HEAD holds a baseline. A first staged baseline is compared against contract policy when HEAD holds none. The queue checks while the limit is on.

For a pstack-t3 checkout without a pre-commit hook, run `h=$(git rev-parse --git-path hooks/pre-commit) && test ! -e "$h" && printf '#!/bin/sh\nexec python3 skills/landing/scripts/land.py size --staged\n' > "$h" && chmod +x "$h"`.

Split an over-limit file before landing. Code moves one responsibility to a sibling module. Tests start a new file for the feature and share helpers. Skill and doc text moves rarely needed sections to an on-demand file with a pointer saying when to read it.

One limit is known. A relative entry trusts the reference file's own content, so a project that needs the reference pinned guards it separately, and this repository pins vendored files through `t3/overrides.lock.json`.

Raise the limit with a reviewed PR a person merges outside the queue. The queue cannot raise an allowance, raise the maximum or remove its effect, or turn the limit off. A person raises an allowance that way, and turns the limit off that way by removing enabled policy while the contract sets no maximum, then a rerun of `init` without flags keeps the stored maximum and with `--max-file-tokens` changes it.

Skipped paths never count. Contract generated paths stay out. Top-level vendor tree stays out. Images stay out by extension case-insensitive, including png jpg jpeg gif webp ico svg and pdf. Lockfiles stay out by basename at any depth, including package-lock.json pnpm-lock.yaml yarn.lock go.sum and any lock file. Top-level Python cache stays out, with *.pyc at any depth. The baseline file itself stays out. This repository also skips its generated skills docs/cli and docs/skills.md through its contract generated paths and its committed baseline skip.
